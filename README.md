# CoSTA
Costal Salinity and Temperature Array

A low-cost, open-source sensor array that measures temperature and conductivity

It was developed as part of my M.S. thesis in Ocean and Resources Engineering (ORE) at the University of Hawaiʻi at Mānoa, in the [MILLO Group (Pagniello Lab)](https://pagniello-lab.github.io).

**Author:** Kaja Reinhardt, University of Hawaiʻi at Mānoa

**Thesis:** A Distributed, Low-Cost Sensor Array for Measuring Spatiotemporal Salinity Variability in Coastal Waters (December 2026)
